# Predicting House Price with Multiple Linear Regression
A real estate dataset to perform Exploratory Data Analysis (EDA) and create a Multiple Linear Regression (MLR) model to predict the Price of a house based on various features such as Square Feet, Number of Bedrooms, Number of Bathrooms, and other factors.
## House Price Prediction Using Machine Learning

1. Project Overview

This project explores how machine learning can be used to predict residential property prices based on different property characteristics. The objective is to understand the relationship between property features and selling prices and evaluate the performance of different predictive models.

2. Business Problem

Accurately estimating property prices can help buyers, sellers and real estate professionals make better-informed decisions. This project investigates whether property characteristics such as floor area, number of bedrooms, bathrooms, garage size and location scores can be used to estimate property values.

3. Tools and Technologies

Python
Pandas and NumPy
Matplotlib and Seaborn
Scikit-learn
Jupyter Notebook

4. Methodology

The dataset was explored and prepared before developing two machine learning models:
Multiple Linear Regression
Random Forest Regression

The dataset was divided into training and testing sets using an 80:20 split. Model performance was evaluated using Root Mean Squared Error (RMSE).

5. Results and Findings
The Multiple Linear Regression model achieved an RMSE of approximately 63,952, while the Random Forest model achieved approximately 71,733.
The results indicate that Multiple Linear Regression performed better on this particular test dataset, producing lower prediction errors.

6. Business Insights
The results demonstrate how property characteristics can be used to estimate residential property prices. The comparison also highlights the importance of selecting an appropriate predictive model based on actual testing performance rather than assuming a more complex model will always perform better.
